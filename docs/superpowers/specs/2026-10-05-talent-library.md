# 天赋图书馆 1.0 — 用户已确认的设计

面向 RimWorld 1.6；一个书写台、一个 2×1 展示书柜、一种有品质的通用技能书。
写作不生产报纸、地图、蓝图、杂志。独立 Writing/Reading 工作类型。
普通品质每 60 个实际阅读 ticks：低于18级的双火随机一项+20最终XP；双火全部达标后，低于18的单火随机一项+15；全部有火达标后，15–20总XP平均分配给可学习且低于10的技能。无火直接通识；衰减后重新优先培养。精确截断18/10，禁用技能不参与、不堵塞。
品质倍率：0.50/0.75/1.00/1.25/1.50/1.75/2.00。最终经验不再次乘天赋、学习倍率；遵循原版每日经验饱和（4000后减至20%），并计入每日经验。书柜与图书馆不再额外乘自定义技能经验，避免叠加。
作者知识=0.5智识+0.5最高四项可用技能均值；知识品质上限在4/8/12/15/18依次开放普通/良好/极佳/大师/传奇，低于4至多较差；概率随知识提高。
心灵绘卷永久解除工作/技能禁用（保存标记、保留背景；不恢复缺失肢体/意识，不绕过疾病和物理条件）。寸长寸强移除近战爱好者；寸短寸狠增加；重复无效使用禁用，不倒推技能。三者玩家手动指定目标，一次性消耗，自动阅读排除。
新增材料与成本：通用书50布、60000工作量；特殊书通过贸易/任务/开发模式获取，书写台只写通用书。Harmony为唯一外部依赖。素材使用用户提供VBE写作台与书贴图，保留来源署名。
验收：可编译DLL；真实C#核心行为测试；Def/贴图引用检查；不宣称在RimWorld实测。
